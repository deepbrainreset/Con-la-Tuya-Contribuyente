# Con La Tuya Contribuyente

CivicTech / GovTech web platform focused on making public spending and political information easier to explore, understand, and audit through an interactive digital experience.

## Overview

Con La Tuya Contribuyente is an end-to-end web product that combines structured public-information interfaces, interactive maps, dashboards and data visualisation. The project was built as a practical product rather than a static frontend exercise, with emphasis on navigation, information architecture, responsive UI and extensible application structure.

## Tech Stack

- React 19
- TypeScript
- Node.js / Express
- Vite
- React Router
- Leaflet + React-Leaflet
- Recharts
- Tailwind CSS
- Motion
- REST-oriented application architecture
- Google Gemini integration capability

## Key Product Areas

- Interactive geographic exploration with Leaflet
- Data dashboards and visualisation with Recharts
- Responsive React interface
- Client-side routing and structured navigation
- Node/Express server layer
- AI-ready architecture using Google Gemini
- Component-based TypeScript codebase

## Development Approach

This project was developed using an AI-assisted engineering workflow. AI coding tools are used as development accelerators for implementation, debugging, refactoring and iteration, while product definition, architecture decisions, integration, testing and final output remain under human direction and review.

The objective of this workflow is not simply code generation: it is rapid product iteration while maintaining ownership of the complete application lifecycle.

## Local Development

### Prerequisites

- Node.js
- npm

### Setup

```bash
npm install
```

Create a local environment file from `.env.example` and configure only the services required for your environment.

```bash
npm run dev
```

Type checking:

```bash
npm run lint
```

Production build:

```bash
npm run build
```

## Security

Runtime credentials and local environment files are intentionally excluded from version control. `.env.example` contains placeholders only and must never contain production credentials.
